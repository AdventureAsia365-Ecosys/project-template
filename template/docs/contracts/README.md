# Contracts

A contract is a view, an API or an event that another app or an outside system depends on. Each one gets a folder
from the template [`../templates/contract.md`](../templates/contract.md): a JSON Schema, one valid and one invalid
sample, and a row in the registry below. A breaking change is a new version, never an edit in place.
