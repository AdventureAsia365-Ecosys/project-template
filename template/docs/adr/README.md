# Architecture decision records

One file per decision that is hard to reverse: `NNNN-<slug>.md`, from the template
[`../templates/adr.md`](../templates/adr.md). An accepted ADR is never rewritten: a change is a new ADR that
supersedes it, or an amendment file `NNNNa-<slug>.md`.

## Numbering

Take the next free number from the index below. Reserve a number by adding its row in the same PR as the file.

## Prune

At each 90-day review, mark superseded ADRs as such and link the one that replaces them.
